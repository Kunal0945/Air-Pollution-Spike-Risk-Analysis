# Air Pollution Spike Risk Analysis

This project analyzes air quality data to identify Indian cities with high pollution spike risk using Python and Power BI.

## Problem Statement
Average AQI values often hide sudden pollution spikes, which are more harmful to public health.
This project focuses on identifying cities where pollution spikes are significantly higher than normal levels.

## Key Concept
**Risk Gap = Peak Pollution − Average Pollution**
A higher risk gap indicates severe or frequent pollution spikes, even if average AQI appears moderate.

## Methodology
1. Loaded raw AQI dataset
2. Cleaned and handled missing values
3. Aggregated data city-wise
4. Calculated average AQI, peak AQI, and risk gap
5. Identified top 10 high-risk cities
6. Built interactive dashboard in Power BI

## Key Insights
- Some cities show moderate average AQI but very high pollution spikes
- Risk gap is a better indicator of pollution severity than average AQI alone
- Sudden pollution spikes pose serious short-term health risks
